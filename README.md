# Emunium documentation

**Browser automation. At the OS level.**

[Read the docs](https://emunium.github.io/docs/) · [Quick start](https://emunium.github.io/docs/quick-start/) · [Python library](https://github.com/DedInc/emunium)

Emunium is a Python library that reads browser pages through an extension and
controls them with the real mouse and keyboard. It combines familiar locators
with native input, verified clicks, persistent browser profiles, and configurable
pointer movement and typing rhythm.

This repository is home to [emunium.github.io](https://emunium.github.io/):
the guides, examples, and API reference for Emunium. Start with your first script,
set up your browser, then look up the details as you build. The library and its
source code live in [DedInc/emunium](https://github.com/DedInc/emunium).

## Start here

- **Your first script:** [Installation](https://emunium.github.io/docs/installation/) and [Quick start](https://emunium.github.io/docs/quick-start/).
- **Your browser and profile:** [Browser setup](https://emunium.github.io/docs/browsers/) and [connecting to an existing profile](https://emunium.github.io/docs/connect/), including Firefox and Camoufox.
- **Working with pages:** [Locators and assertions](https://emunium.github.io/docs/locators/) and [waiting for changes](https://emunium.github.io/docs/waiting/).
- **Real mouse and keyboard input:** [Input actions](https://emunium.github.io/docs/mouse-and-keyboard/) and [motion and typing presets](https://emunium.github.io/docs/human-like-input/).
- **Beyond the browser:** [Desktop automation with image matching and OCR](https://emunium.github.io/docs/standalone/).

See the [limitations](https://emunium.github.io/docs/limitations/) for platform
requirements and the [changelog](https://emunium.github.io/changelog/) for release changes.
